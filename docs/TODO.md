## 0단계: 가능성 확인용 시제품 (완료)

목표: "브라우저만으로 한글 라벨 사진을 읽을 수 있는가"를 본격적으로 만들기 전에 확인한다.

- [x] 0-1. 파일 하나짜리 시제품으로 성분 사전과 판정 흐름 만들어 보기 (PRD #4-3, #4-4)
- [x] 0-2. Tesseract.js 한국어 인식을 브라우저에서 실행해 보기 (PRD #4-2, #7)
- [x] 0-3. 화질이 다른 예시 라벨 이미지 3장으로 인식률 확인하기 (PRD #9)
- [x] 0-4. 확인 결과를 PRD의 가정과 열린 질문에 반영하기 (PRD #8, #9)

확인 방법: `prototype/index.html`을 열어 예시 라벨을 누르면 판정이 나온다.

알게 된 것:
- 깨끗한 이미지는 거의 정확하게 읽었지만, 흐리고 조명이 고르지 않은 이미지는 아무 글자도 읽지 못했다.
- 조명 얼룩을 평평하게 펴는 전처리를 넣자 세 장 모두 읽혔다. 이 전처리를 4단계에 정식 할 일로 넣었다.
- 글자를 못 읽었는데 "문제 없음"이 뜨는 위험한 경우를 발견했다. 5단계에 막는 할 일을 넣었다.

목표: 식단과 알레르기를 눌러서 고르고, 새로고침해도 유지된다.

- [x] 2-1. 식단 6개 선택 버튼 만들기 (PRD #4-1)
- [x] 2-2. 한국 표시 대상 알레르기 선택 버튼 만들기 (영어와 한국어 함께 표기) (PRD #4-1, #6)

## 3단계: 성분 사전과 판정

목표: 원재료명 글자를 붙여 넣으면 판정과 이유가 나온다.

- [ ] 3-1. 한국 라벨 용어 사전 `js/dictionary.js` 만들기 (한국어, 영어, 태그) (PRD #4-3)
- [ ] 3-2. 글자에서 사전 단어를 찾는 `js/matcher.js` 만들기. 긴 단어부터 찾기 (PRD #4-3)
- [ ] 3-3. 식단·알레르기별로 "먹을 수 없음 / 확인 필요 / 문제 없음" 판정하기 (PRD #4-4)
- [ ] 3-4. 글자 입력칸과 예시 라벨 3종 버튼 만들기 (PRD #4-4, #10)
- [ ] 3-5. 판정이 맞는지 확인하는 테스트 페이지 `tests/index.html` 만들기 (PRD #10)

## 4단계: 사진에서 글자 읽기

목표: 사진을 올리면 원재료명 글자가 입력칸에 채워진다.

- [ ] 4-1. 사진 찍기/고르기 버튼, 끌어다 놓기, 붙여넣기 만들기 (PRD #4-2)
- [ ] 4-2. Tesseract.js로 한국어 글자 인식하는 `js/ocr.js` 만들기 (PRD #4-2, #7)
- [ ] 4-3. 인식 전 사진 전처리 (확대, 조명 얼룩 펴기, 대비 높이기) (PRD #4-2, 0단계 결과)
- [ ] 4-4. 인식 진행률 표시와, 실패했을 때 직접 입력하라는 안내 (PRD #4-2, #3)
- [ ] 4-5. 앱 안에서 카메라 켜고 촬영하기: 후면 카메라, 가이드 틀, 틀 영역만 잘라 인식 (PRD #4-6) *(10/29 추가)*
- [ ] 4-6. 카메라를 쓸 수 없을 때(권한 거부, https 아님) 사진 고르기로 안내 (PRD #4-6, #7) *(10/29 추가)*

확인 방법: 예시 라벨 사진을 올리거나 앱 안 카메라로 찍으면 글자가 채워지고 판정이 바뀐다.

- [ ] 5-4. 원문에 걸린 성분 강조 표시 (PRD #4-4)
